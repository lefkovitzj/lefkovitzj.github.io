A live demo is currently available at https://wdw-wayfinder.lefkovitzj.com/, hosted on Render's free tier, so initial boot times may be slow if the application does not have recent traffic.

Official Walt Disney World planning tools are useful for direct point-to-point navigation, but they typically underperform for resort-to-resort travel, chained itineraries, and multi-stop optimization. They often miss the practical complexity of transfers, non-obvious routing options, and the tradeoffs required when building an efficient day plan with several destinations.

There's just too much data and too many constraints for a human to reliably optimize without computational assistance, and that's where WDW Wayfinder comes in. By modeling the entire transit network as a directed graph and applying pathfinding and optimization techniques, the tool identifies the best possible routes across the entire system — not just the most obvious ones.

One of my many interests is optimization and strategy, and I have a particular passion for Disney parks, so this project was a natural fit to combine those interests. Originally built as a learning tool to better understand graph theory, this project has evolved substantially. To make the system functional I had to research and create a custom dataset for all the possible routes within the Walt Disney World transportation system. This too, is included under the MIT open-source license the project uses, and could be used for other applications beyond this project.

This project is one of my first attempts at partially using AI-assisted development while building an application. AI tools such as GitHub Copilot were used to help brainstorm, prototype, and refactor parts of the code - especially the frontend design and JavaScript, with final design and validation decisions made manually. Much of the debugging was also done manually when artificial intelligence tools produced incorrect, inefficient, or otherwise suboptimal code.

The project uses FastAPI for the backend, HTMX for dynamic frontend interactions, Tailwind CSS for styling, and Docker for containerization. The system models the entire Walt Disney World transportation network as a directed weighted multigraph, where nodes represent locations (parks, resorts, transportation hubs) and edges represent transit routes with weights corresponding to travel times. A modified Held-Karp algorithm is implemented to solve the optimization problem of finding the most efficient route given a set of start and endpoints as well as a list of intermediate destinations.
